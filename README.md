# Datasets
This repo contains public datasets for machine learning and data analysis experiments.

## Files

- `creditcard.csv`
  - A credit card transactions dataset with anonymized features.
  - Columns include `Time`, `V1` through `V28`, `Amount`, and `Class`.
  - Commonly used for fraud detection research: `Class` indicates whether a transaction is fraudulent.

- `spam.csv`
  - A labeled SMS dataset for spam detection.
  - Columns include `v1`/`V1` (message label such as `ham` or `spam`) and `v2`/`V2` (SMS text).
  - Useful for training text classification and natural language processing models.

- `data.csv`
  - A movie review sentiment dataset.
  - Columns include `review` and `sentiment`.
  - Contains text reviews paired with sentiment labels like `positive` or `negative`.

## Usage

Use these files with standard data science tools such as Python `pandas`, R, or machine learning libraries.
